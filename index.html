02 Ambient AI Windows · Local-only · Zero-dependency core

AETHER

A quiet local-first overlay that watches a redacted snapshot of what you're doing, asks a model on your own machine for one useful nudge, and disappears again. It observes — it never acts.

redacted context · one nudge · auto-hide
Problem
Every "AI assistant" wants your screen, your clipboard, your keystrokes, and a monthly subscription.
Build
A frameless tkinter card samples coarse context — active app, window title, idle time, a clipboard hash, your git branch — then asks Ollama for a single suggestion.
Engineering
PII is scrubbed before the prompt is ever built, there is no execution path at all, and cooldowns plus an hourly budget mean it can't nag. The core runs on the standard library alone.
Python Ollama tkinter SQLite

03 Computer Vision Browser · Real-time

HandChord

A touchless musical instrument that tracks 21-point hand landmarks using Google MediaPipe and synthesizes dynamic polyphonic chords and arpeggios directly in the browser via the Web Audio API.

21 landmarks · per frame
Problem
Instruments need physical strings or keys — I wanted chords that come out of a gesture, with nothing in your hands.
Build
Webcam input mapped through MediaPipe landmarks into polyphonic chords and arpeggios that respond as you move.
Engineering
Web Audio API synthesis in the browser with a Vite build — inference and sound stay client-side, so latency stays playable.
JavaScript MediaPipe Web Audio API Vite

04 Hardware & IoT ESP32 · Working prototype

KrishiTrust / KrishiPath

An IoT agricultural telematics prototype combining an ESP32 microcontroller, 6-axis accelerometer/gyroscope (MPU-6050), and GPS to log transit vibration and protect produce across mountain transport routes.

vibration score · gps roadDNA
Problem
Produce is damaged on rough mountain transport routes, and the damage is invisible until the goods arrive.
Build
An ESP32 logger pairing an MPU-6050 accelerometer/gyroscope with GPS to record transit shock the whole way down.
Engineering
Six-axis I²C sampling turned into a vibration score tied to GPS position, so bad road segments can be identified precisely.
ESP32 MPU6050 C++ React
